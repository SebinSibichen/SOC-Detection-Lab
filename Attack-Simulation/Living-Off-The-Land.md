# Attack Simulation 11 — Living Off The Land Binaries (LOLBins)

## Objective

Validate Windows process-creation logging for selected legitimate Windows utilities that can be abused by attackers.

## Lab Environment

* Operating System: Windows 11 VM
* SIEM: Splunk Enterprise
* Telemetry: Sysmon
* Event ID: 1 — Process Create
* Splunk index: `main`
* Target hostname: `TargetMachine`

## Binaries Investigated

| Binary        | Potential abuse                                 |
| ------------- | ----------------------------------------------- |
| certutil.exe  | File transfer or certificate-related operations |
| bitsadmin.exe | Background file transfers                       |
| mshta.exe     | HTML Application execution                      |
| regsvr32.exe  | Component registration and script-related abuse |
| rundll32.exe  | DLL function execution                          |

## Test 1 — Confirm Executable Availability

Run in PowerShell:

```powershell
Get-Command certutil.exe, bitsadmin.exe, mshta.exe, regsvr32.exe, rundll32.exe -ErrorAction SilentlyContinue |
Select-Object Name, Source
```

Expected result: Windows resolves the executable paths.

## Test 2 — Generate a Benign Process Event

Run:

```powershell
certutil.exe -?
```

This requests the command-line help information. It does not download or decode a file.

## Test 3 — Verify Local Sysmon Logging

Run:

```powershell
Get-WinEvent -FilterHashtable @{
    LogName = 'Microsoft-Windows-Sysmon/Operational'
    Id = 1
} -MaxEvents 20 |
Where-Object { $_.Message -match 'certutil\.exe' } |
Select-Object -First 5 TimeCreated, Id, Message |
Format-List
```

Expected result: A process-creation event containing `certutil.exe`.

## Test 4 — Verify Splunk Ingestion

Search in Splunk:

```spl
index=main source="WinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1
| search Image="*certutil.exe"
| table _time ComputerName User ParentImage Image CommandLine
| sort - _time
```

## Observed Results

* Sysmon process-creation events were present locally.
* Splunk returned a `certutil.exe` event.
* The observed command line was `certutil.exe -?`.
* The parent process was PowerShell.
* The event was generated by the lab user on `TargetMachine`.

## Conclusion

The test validates process-creation logging and forwarding to Splunk.

It does not demonstrate malicious behavior. No download, remote script execution, or file decoding was performed during this test.

**Status:** Telemetry validation successful; suspicious-behavior detection requires additional testing.
