## Screenshot 03 – Splunk Detection Query

### `03-splunk-scheduled-task-detection-Query.png`

Shows the SPL query used to detect Scheduled Task creation.

Detection query:

```spl
index=main EventCode=1
| search Image="*\\schtasks.exe"
| search CommandLine="*/create*"
| where NOT like(Image,"%SplunkUniversalForwarder%")
| table _time ComputerName User Image ParentImage ParentCommandLine CommandLine
| sort - _time
```

**Purpose:** Demonstrates the SOC detection logic implemented in Splunk.
