# Detection Rule Screenshots

This directory contains screenshots for every detection rule implemented in this project.

Each detection has its own folder containing the investigation workflow.

Example:

```
Process-Creation/
│
├── 01-Search-Query.png
├── 02-Search-Results.png
├── 03-Expanded-Event.png
├── 04-Full-Event-Details.png
├── 05-Interesting-Fields.png

```

Every detection follows the same documentation format to maintain consistency throughout the project.
