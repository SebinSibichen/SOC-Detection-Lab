# MITRE ATT&CK Mapping — PowerShell

## Detection Overview

This detection monitors PowerShell process execution and examines command-line arguments and parent-process context to identify potentially suspicious scripting activity.

## ATT&CK Mapping

| Field                      | Details                                                  |
| -------------------------- | -------------------------------------------------------- |
| Official ATT&CK Identifier | T1059.001                                                |
| Official Technique Name    | Command and Scripting Interpreter: PowerShell            |
| Tactic                     | Execution                                                |
| Supporting Event           | Sysmon Event ID 1 — Process Create                       |
| Supporting Fields          | `Image`, `CommandLine`, `ParentImage`, `User`, `UtcTime` |
| Mapping Confidence         | Appropriate when PowerShell execution is observed        |
| Validation Status          | Confirm the query matches the intended activity          |

## Mapping Rationale

PowerShell is a command and scripting interpreter frequently used for administration, automation, and adversary activity.

Sysmon Event ID 1 can identify PowerShell process launches and expose their command-line arguments. This provides useful evidence for investigating PowerShell execution.

## What the Evidence Does Not Demonstrate

* That the PowerShell command was malicious.
* That the command completed successfully.
* That a payload was downloaded or executed.
* That the endpoint was compromised.
* That all PowerShell activity is suspicious.

## Validation Notes

Validate the query against a controlled PowerShell execution and review representative benign PowerShell activity. Where available, correlate process creation with PowerShell Script Block Logging events such as Event ID 4104.
