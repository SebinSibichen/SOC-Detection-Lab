# MITRE ATT&CK Mapping - PowerShell Execution

## Overview

The PowerShell Execution detection monitors PowerShell process creation
on Windows systems using Sysmon Event ID 1.

PowerShell is a legitimate administrative tool, but attackers may also
abuse it to execute commands and scripts.

---

## MITRE ATT&CK Technique

### T1059.001 - PowerShell

**Tactic:** Execution

**Technique:** Command and Scripting Interpreter: PowerShell

---

## Mapping Rationale

The detection identifies the execution of:

```text
powershell.exe
```

and captures the command line associated with the process.

This telemetry can help an analyst determine whether PowerShell was used
for legitimate administration or potentially malicious execution.

---

## Relevant Telemetry

| Field        | Purpose                                         |
| ------------ | ----------------------------------------------- |
| Image        | Identifies PowerShell                           |
| CommandLine  | Shows the executed command                      |
| ParentImage  | Identifies the process that launched PowerShell |
| User         | Identifies the account running PowerShell       |
| ComputerName | Identifies the affected endpoint                |
| `_time`      | Identifies when the activity occurred           |

---

## Detection Query

```spl
index=main EventCode=1
| search Image="*\\powershell.exe"
| table _time ComputerName User Image ParentImage CommandLine
| sort - _time
```

---

## Lab Classification

The PowerShell execution used in this project was:

**Classification:** Benign / Authorized Lab Activity

The commands were intentionally executed to validate the SOC detection
pipeline.

---

## Important Analyst Consideration

PowerShell execution alone does not prove malicious activity.

Analysts should investigate:

* Command-line arguments
* Parent process
* User account
* Network connections
* File creation
* Encoded commands
* Download activity
* Other events occurring around the same timestamp

---

## Conclusion

The detection provides visibility into PowerShell execution and maps
to MITRE ATT&CK T1059.001.

The mapping represents the observed use of PowerShell as a command and
scripting interpreter and does not by itself indicate that the activity
was malicious.
